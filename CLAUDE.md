## Agent skills

### Issue tracker

Issues live in GitHub Issues on `gbarrueto/ventana-celeste` (uses the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Domain docs

Reference docs live in `docs/` (see `docs/README.md` for the index) plus `docs/adr/`. There is no
root `CONTEXT.md`. See `docs/agents/domain.md`.

### Documentation style

Writing any `.md` in this repo: follow `.claude/skills/docs-style/SKILL.md`. Reference docs describe
what exists. Pending work is tracked in the issue tracker, not in the docs.
